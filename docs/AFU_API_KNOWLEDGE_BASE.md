1. **官方定位差异**：Anthropic 将 Sonnet 专项调优为“代码与 Agent 利器”，而 Opus 主攻“文学创作、商业策划与哲学深思”；

3. **性价比悬殊**：Astra (3.0x) 和 Opus (2.5x) 单次调用是 Sonnet 的 2~3 倍价格，但在实际工程代码通过率上并未提升。

## 5. 买家专属 Key 独立用量查询与私有账本机制

### 5.1 核心架构：100% 独立私有账本 (Zero-Abuse & Isolation)
* **绝对私有隔离**：每个购买算力套餐的用户，系统都会生成一把唯一的 `sk-aurora-xxx`。
* **独立数据库记录**：用户的密钥记录在 `data/api-db.json` 中，包含 `tokensRemaining`（剩余额度）、`tokensUsed`（累计消耗）、`totalTokens`（套餐总额度）与 `lastCallInfo`（最近一次调用小票）。
* **严格澄清**：用户或客户端查询到的余额，**100% 仅代表当前这把专属 Key 自己的私有余额**，**绝不是**整个平台的资金池余额！多用户并发互不影响，彻底杜绝公用混淆或被他人蹭额度。

### 5.2 算力管家自然语言查询规范 (Chat Commands)
用户在任意接入的客户端（如 WorkBuddy、Cursor、NextChat、ChatBox 等）中，**无需打开后台网页**，直接在聊天框发送自然语言指令，网关会自动秒级拦截并回复私有账单：

1. **查询剩余额度**：
   * 发送：`查余额`、`还剩多少额度`、`查询我的token`、`我的套餐`
   * **系统自动回复专属小票格式**：
     ```text
     🔑 专属密钥：sk-aurora-f***9d8d
     ⚡ 剩余算力：6,118,663 Tokens（约 6.12 百万 Tokens）
     📊 累计消耗：881,337 Tokens（约 88.1 万 Tokens）
     📦 套餐总量：7,000,000 Tokens（7 百万 Tokens）
     🏷️ 套餐类型：面包多自动发卡·主力畅享包
     🛡️ 状态 / 有效期：ACTIVE · 永久有效不过期
     💡 可用预估：按常规对话/编程任务（平均约 3k~5k tokens/轮）计算，剩余额度大约还可支持 1,200 ~ 2,000+ 轮交互。
     ```
2. **查询上一轮消耗**：
   * 发送：`我刚才花了多少token`、`上一次提问消耗多少`、`上一轮账单`
   * 系统会精确列出上一轮调用的模型、`Prompt Tokens`、`Completion Tokens` 及扣费明细。
3. **查询模型定价**：
   * 发送：`哪个模型最便宜`、`模型价格`、`推荐便宜模型`

### 5.3 HTTP 响应头实时静默透传
每次正常的 API 交互（`/v1/chat/completions`），后端均在 Response Headers 中返回最新额度，前端可无感实时显示：
* `X-Remaining-Tokens`: 6118663
* `X-Consumed-Tokens`: 1250
* `X-Remaining-Credits`: 6.12M

## 7. 安全脱敏与网关开发规范 (Anti-Leak & Safety)

1. **彻底杜绝公用 Demo Key**：
   * 系统严禁内置公用 Key（如 `sk-aurora-demo-8888` 已正式标记为 `RETIRED` 401 拦截），所有在 Playground 与客户端发起的调用必须绑定用户浏览器专属 Key。
2. **上游报错脱敏清洗 (`sanitizeUpstreamError`)**：
   * 严禁向上游报错中透露 `afugpt`、`one-api`、`new-api` 或内部分组 Key，所有上游错误统一转换为极光集群标准错误响应。
3. **多模态自动升配**：
   * 当用户上传图片但选了纯文本模型时，`routeUpstreamTarget` 会自动且无感升配至 `claude-sonnet-4-6` 或 `gemini-3.8-flash` 视觉通道，确保用户体验不中断。
