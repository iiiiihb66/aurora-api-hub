## 2. 核心技术架构与智能网关引擎

### 2.1 智能分层上游路由矩阵 (Tiered Cost Routing)
系统在网关层将上游阿福 5 组不同倍率的 API Key 进行精确标签化管理，根据用户请求模型与请求载荷实时路由：

1. **海外特惠专线 (0.08x 倍率)**：
   - 调度模型：`gpt-6-astra`, `gpt-5.5`, `gpt-5.6`, `aurora-coder`
   - 网关对买家收取 2.0x~3.0x，上游实际支出仅 0.08x，**净利差高达 25~37 倍**。
2. **海外特价专线 (0.20x 倍率)**：
   - 调度模型：`claude-3-5-sonnet`, `claude-opus-4-7`
   - 网关对买家收取 2.0x，上游支出 0.20x，**净利差 10 倍**。
3. **国产特价通道 (0.50x 倍率)**：
   - 调度模型：`doubao-seed-2-0-pro`, `deepseek-chat` 兼容通道。
4. **默认多模态视觉保底池 (1.00x 倍率)**：
   - 调度模型：`gemini-3.7-flash`, `gpt-4o` 视觉模态。

### 2.2 多模态智能感知识别与无感自动升配 (Auto-Vision Upgrade)
- **痛点**：用户在第三方客户端（如 Cursor、NextChat）选中纯文本模型后传入了图片（Base64 或 URL），直接调用上游纯文本通道会报错崩溃。
- **解法**：网关内置 `hasImageContent()` 深度报文探针：
  - 一旦侦测到 `image_url` 或 `data:image/`，系统**无感自动升配**为支持视觉的多模态通道（如 `gemini-3.7-flash`）；
  - 既保障了 100% 成功返回图片分析结果，又避免了向用户抛错。

### 2.3 毫秒级 Token 真实扣费与并发限流
- 废弃传统粗暴的“按次扣费”，网关解析上游返回的真实 `prompt_tokens` 与 `completion_tokens`；
- 结合模型的倍率系数进行原子性计算扣减并持久化至 `data/api-db.json`；
- 内置滑动窗口频控（默认 80 RPM/Key），杜绝恶意脚本并发攻击。

## 3. 支付履约与自动化交付闭环设计

对于个人独立开发者，自动化交付是实现 24 小时无人值守躺赚的关键。平台目前设计并实现了两条交付闭环：

### 3.1 面包多原生闭环模式 (Zero-Threshold Native Delivery)
- **核心优势**：无需个体户执照、无需工信部网站备案、无需媒体平台创作者认证。
- **履约机制**：
  1. **一单一密卡密库**：通过网关 `/api/admin/cards/generate` 预批量生成 20~100 个 Key；
  2. **买家付款即得**：买家通过微信或支付宝扫码付款 ¥1.00 / ¥5.00 / ¥15.00；
  3. **屏幕秒级弹卡**：面包多在支付成功页和买家“我的已购”中当场展示独享的 `sk-aurora-xxxx` 与接入教程；
  4. **资金闭环**：平台款项扣除极低手续费后自动提现至绑定的创作者支付宝。

### 3.2 爱发电订单自提 / 私信扫单机器人闭环 (Afdian Auto-Fulfillment)
- **核心机制**：
  - 针对爱发电未认证账号无法使用原生卡密池的问题，网关采用**【订单号映射自提引擎】**；
  - 方案 A（自提页）：买家付完款后在极光官网输入爱发电订单号（如 `202512131612...`），系统校验到账后直接在前端激活并弹出一张全新 Key；
  - 方案 B（扫单守护）：网关跑后台定时器（`auto_fulfill_daemon.js`），每 10 秒轮询爱发电赞助清单，自动向买家私信下发 Key。

## 4. 0 成本生产环境部署与上线蓝图

为了让任何人通过公网域名访问极光 API，推荐采用以下全免费架构：

```
[买家客户端 (Cursor / 微信 / 网页)]
            │
            ▼ (HTTPS 加速)
[Cloudflare 免费全球 CDN]
            │
            ▼ (Cloudflare Tunnel 穿透，无需公网 IP)
[极光 API 网关 (本地电脑 / 腾讯云轻量 2核2G)]
            │
            ├─► [独立前端控制台] (端口 3005)
            ├─► [OpenAI 兼容中枢] (/v1/*)
            └─► [上游阿福智能路由池] (5 组 Key 自动故障转移)
```

1. **域名与证书**：使用 Cloudflare 免费提供 SSL，彻底告别浏览器证书风险告警；
2. **免公网 IP 穿透**：使用 `cloudflared tunnel`，本地启动即可拥有公网 `https://api.yourdomain.com`；
3. **数据安全性**：底层阿福 5 组真实 Key 仅存储在服务端 `.env`，对外所有交互均为虚拟生成的 `sk-aurora-*`。
