03 / INTEGRATION ARCHITECTURE

Plug and play
in 10 seconds.

无需安装任何特定插件，任何支持自定义 OpenAI 接口地址的桌面软件与开发环境均可直接秒级调用。

01

Cursor & VS Code

打开 Settings ➔ Models ➔ OpenAI API Key，勾选开启 Override OpenAI Base URL，填入 http://localhost:3005/v1，输入专属 Key，开启 aurora-coder 即可随意 Cmd+K 极速编程！

02

NextChat & Web Tools

打开 NextChat 或 沉浸式翻译插件，选择自定义服务商，API Host 填入 http://localhost:3005/v1，输入您的 Key 并配置模型，点击右上角查询余额即可回显百万算力。

03

Cherry Studio & ChatBox

在设置中选择添加 OpenAI 兼容服务商，Base URL 填入统一网关地址，添加模型代号 aurora-coder 或 gpt-6-astra，保存即可开启打字机流式对话。

04

Python SDK & cURL

直接使用官方 from openai import OpenAI，实例化时指定 base_url 和 api_key，即可无感复用原有工程全套提示词与 Agent 工作流。
